# Preguntas de investigación

1. ¿De dónde sale hoy la identidad usada por HTTP, voz y herramientas de wallet?
2. ¿Cómo selecciona el backend la wallet y dónde asume una instancia compartida?
3. ¿Qué distingue una wallet cuyo owner es un usuario de una controlada por el servidor en Privy?
4. ¿Qué evidencia permite vincular una wallet con la identidad verificada sin confiar en una dirección enviada por el navegador?
5. ¿Qué flujos documenta Privy para firma del usuario, firmantes del servidor y recuperación en otro dispositivo?
6. ¿Qué pruebas existentes cubren confirmación, idempotencia y resultados inciertos? ¿Cuáles faltan para el navegador multiusuario?
